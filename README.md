# My First C++ Game

This is a console-based mini-game written in C++. 
The player needs to control the character to avoid the hunters while collecting coins.ps using wasd to play use q to quit.

## How to Run
Compile the source code `move chase coin nondisappear final.cpp` using any C++ compiler (such as g++, Dev-C++, or Visual Studio) and run the generated executable.
